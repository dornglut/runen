# A0 Verification Contract

Status: **non-normative conformance-oracle documentation**

This document owns the test obligations for the executable A0 oracle. The normative semantics exercised by A0 are owned by `spec/language/core/value-storage.md`.

## Required cases

The A0 suite covers at least:

- move invalidates the source;
- copy preserves the source;
- partial move preserves disjoint live sub-places and makes the aggregate unreadable as a whole;
- independently initialized fields can form a fully initialized aggregate;
- non-copy values cannot be copied;
- `Init` cannot reinitialize Dead storage;
- mutable `Assign` can initialize Never-initialized storage;
- mutable `Assign` can reinitialize Dead storage;
- mutable `Assign` can replace partially initialized aggregate storage while destroying only live old subobjects;
- immutable assignment is rejected;
- assignment destroys a live replacement target before writing the new value;
- explicit partial-aggregate drop destroys only live subobjects;
- moved or already-dropped values are not destroyed twice;
- field and local cleanup order matches the normative value/storage semantics;
- defined fault cleanup destroys each live value exactly once.

## Synthetic fixture values

The executable oracle may use synthetic non-copy resource values with observable destruction solely to make ownership and destruction behavior testable. Such fixtures are not Runen language primitives.

## Oracle independence

The oracle must model Runen state explicitly. Host ownership, host destruction, native addresses, allocator identity, container order, and host scheduling are not semantic oracles.
