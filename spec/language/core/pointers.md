# Core Pointers and Provenance

Status: **provisional normative; incomplete**

Runen distinguishes a numeric address from a language pointer or reference.

A pointer is not semantically defined as merely an integer address.

Pointer validity may depend on provenance, the referenced storage object, access permission, lifetime, and address-stability constraints.

Resource permission and security authority are separate concepts from pointer provenance.

The precise pointer-construction, dereference, provenance, integer-conversion, relocation, and pinning rules are not defined by this revision.
